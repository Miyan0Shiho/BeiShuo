**目标**

* 启动 FastAPI 后端与前端 Vite 应用，联调 AI 对话（LLM+本地RAG）功能。

**准备**

* 环境变量：设置 `DASHSCOPE_API_KEY`（或 `LLM_API_KEY`）为你的通义密钥。

* 后端端口：`8080`；前端端口：Vite 默认 `5173`；CORS 已允许 `http://localhost:5173`。

* 可选：若未构建过本地索引，执行一次索引构建（已在你机上完成，可跳过）。

**后端启动**

* 命令（在 `python/` 目录）：

  * `export DASHSCOPE_API_KEY=sk-...`（macOS）

  * `uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload`

* 验证：打开 `http://localhost:8080/docs`；`/api/v1/ai/chat`、`/api/v1/ai/chat/stream` 可用。

**前端启动**

* 命令（在 `frontend/` 目录）：

  * `npm install`（首次或依赖更新时）

  * `npm run dev`

* 访问：`http://localhost:5173`

**联调步骤**

* 浏览器控制台设定开发令牌：

  * `localStorage.setItem('token', '<你的JWT>')`

  * 或先调用后端 `/auth/login` 获取真实 Token（数据库未就绪可暂用开发令牌）。

* 页面路径：识别 → “AI阐释”区域 → 输入提问并发送。

* 期望结果：

  * 显示回答文本（LLM）

  * 下方显示“引用来源”标签（来自本地 RAG 检索片段）

**可选验证**

* 非流式接口：`curl -H 'Authorization: Bearer <token>' -H 'Content-Type: application/json' -d '{"recognition_id":"rec_local","message":"九成宫醴泉铭的来历？"}' http://localhost:8080/api/v1/ai/chat`

* 流式接口（SSE）：前端后续可接入 EventSource；后端已支持 `status → references → delta → success` 事件序列。

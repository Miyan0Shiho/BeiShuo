## 设计目标
- 支持碑文数据的存储、检索、标签分类与收藏
- 支持大模型对话的会话管理、消息存储、引用碑文内容的可追溯性
- 支持对话历史访问、反馈与统计
- 兼容前端现有数据结构（如 dynasty、category、image、views 等）
- 建议采用 MySQL 8 / PostgreSQL，字符集使用 utf8mb4，时区统一为 UTC；示例字段类型以 MySQL 为例

## 核心实体与关系
- 用户（Users）1—N 碑文（Inscriptions）
- 碑文 N—N 标签（Tags），N—1 封面与多图（Assets）
- 用户 1—N 会话（Conversations）
- 会话 1—N 消息（Messages）
- 消息 N—N 引用（MessageCitations）指向碑文或文章内容
- 用户 N—N 收藏（Favorites）指向碑文/会话/消息
- 文章知识库（KnowledgeArticles）可挂接标签（Tags）

## 表设计

### 1. users（用户）
- id BIGINT PK
- email VARCHAR(255) UNIQUE NULL
- phone VARCHAR(32) UNIQUE NULL
- password_hash VARCHAR(255)
- nickname VARCHAR(64)
- avatar_url VARCHAR(512)
- status ENUM('active','disabled') DEFAULT 'active'
- created_at DATETIME(3) DEFAULT CURRENT_TIMESTAMP(3)
- updated_at DATETIME(3) DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3)
索引：UNIQUE(email), UNIQUE(phone)

### 2. inscriptions（碑文）
- id BIGINT PK（可用雪花ID，前端示例为 19 位）
- owner_user_id BIGINT FK users(id) NULL（公共库可为空）
- title VARCHAR(255)
- description TEXT
- dynasty VARCHAR(32)（示例：唐代/东汉等）
- year VARCHAR(32)（含公元前文本）
- location VARCHAR(128)
- category VARCHAR(64)（示例：书法碑刻/文学碑刻等）
- cover_image_url VARCHAR(512)
- confidence DECIMAL(5,2) NULL
- views INT DEFAULT 0
- source_type ENUM('upload','import','manual') DEFAULT 'upload'
- status ENUM('draft','published','archived') DEFAULT 'published'
- created_at DATETIME(3)
- updated_at DATETIME(3)
索引：INDEX(dynasty), INDEX(category), FULLTEXT(description)（如使用 InnoDB 全文）

### 3. inscription_assets（碑文素材图片等）
- id BIGINT PK
- inscription_id BIGINT FK inscriptions(id)
- file_url VARCHAR(512)
- width INT NULL
- height INT NULL
- mime VARCHAR(64) NULL（image/png 等）
- sha256 CHAR(64) NULL
- storage_provider VARCHAR(32) NULL（local/s3 等）
- created_at DATETIME(3)
索引：INDEX(inscription_id), INDEX(sha256)

### 4. inscription_text（碑文文本与校对结果）
- inscription_id BIGINT PK FK inscriptions(id)
- ocr_text LONGTEXT NULL
- corrected_text LONGTEXT NULL
- ocr_engine VARCHAR(64) NULL
- ocr_confidence DECIMAL(5,2) NULL
- corrected_by_user_id BIGINT FK users(id) NULL
- corrected_at DATETIME(3) NULL
- updated_at DATETIME(3)
索引：FULLTEXT(ocr_text), FULLTEXT(corrected_text)

### 5. inscription_text_versions（文本版本历史）
- id BIGINT PK
- inscription_id BIGINT FK inscriptions(id)
- content LONGTEXT
- content_type ENUM('ocr','corrected')
- diff_json JSON NULL（可存储差异摘要）
- created_by_user_id BIGINT FK users(id) NULL
- created_at DATETIME(3)
索引：INDEX(inscription_id, content_type), FULLTEXT(content)

### 6. tags（标签）
- id BIGINT PK
- name VARCHAR(64)
- type ENUM('dynasty','script','theme','category','person')
- created_at DATETIME(3)
索引：UNIQUE(name, type)

### 7. inscription_tag_map（碑文-标签关联）
- inscription_id BIGINT FK inscriptions(id)
- tag_id BIGINT FK tags(id)
- PRIMARY KEY (inscription_id, tag_id)
索引：INDEX(tag_id)

### 8. favorites（收藏）
- id BIGINT PK
- user_id BIGINT FK users(id)
- target_type ENUM('inscription','conversation','message')
- target_id BIGINT
- created_at DATETIME(3)
索引：UNIQUE(user_id, target_type, target_id)

### 9. conversations（会话）
- id BIGINT PK
- user_id BIGINT FK users(id)
- title VARCHAR(255) NULL
- related_inscription_id BIGINT FK inscriptions(id) NULL
- system_prompt TEXT NULL
- model_key VARCHAR(64) NULL（如 gpt-4o, glm-4）
- status ENUM('active','archived') DEFAULT 'active'
- created_at DATETIME(3)
- updated_at DATETIME(3)
索引：INDEX(user_id), INDEX(related_inscription_id), INDEX(status)

### 10. messages（消息）
- id BIGINT PK
- conversation_id BIGINT FK conversations(id)
- role ENUM('user','assistant','system','tool')
- content LONGTEXT
- content_format ENUM('text','markdown','json') DEFAULT 'text'
- input_tokens INT NULL
- output_tokens INT NULL
- latency_ms INT NULL
- stop_reason VARCHAR(32) NULL
- parent_message_id BIGINT NULL（线程/追问）
- created_at DATETIME(3)
索引：INDEX(conversation_id, created_at), INDEX(parent_message_id)

### 11. message_citations（消息引用碑文/文章）
- id BIGINT PK
- message_id BIGINT FK messages(id)
- source_type ENUM('inscription','article')
- source_id BIGINT
- source_url VARCHAR(512) NULL
- snippet TEXT NULL（被引用片段）
- extra JSON NULL（如坐标 bbox、页码等）
- created_at DATETIME(3)
索引：INDEX(message_id), INDEX(source_type, source_id)

### 12. message_feedback（消息反馈）
- id BIGINT PK
- message_id BIGINT FK messages(id)
- user_id BIGINT FK users(id)
- rating ENUM('like','dislike')
- comment TEXT NULL
- created_at DATETIME(3)
索引：UNIQUE(message_id, user_id), INDEX(rating)

### 13. model_runs（模型调用明细，可选）
- id BIGINT PK
- message_id BIGINT FK messages(id)
- provider VARCHAR(32)（openai、moonshot 等）
- model VARCHAR(64)
- temperature DECIMAL(3,2) NULL
- top_p DECIMAL(3,2) NULL
- max_tokens INT NULL
- input_token_count INT NULL
- output_token_count INT NULL
- cost_usd DECIMAL(10,6) NULL
- created_at DATETIME(3)
索引：INDEX(message_id), INDEX(provider, model)

### 14. knowledge_articles（知识库文章）
- id BIGINT PK
- title VARCHAR(255)
- author VARCHAR(128) NULL
- dynasty VARCHAR(32) NULL
- content_md LONGTEXT（或 content_html）
- cover_image_url VARCHAR(512) NULL
- status ENUM('draft','published','archived') DEFAULT 'published'
- view_count INT DEFAULT 0
- like_count INT DEFAULT 0
- published_at DATETIME(3) NULL
- created_at DATETIME(3)
- updated_at DATETIME(3)
索引：FULLTEXT(content_md), INDEX(dynasty), INDEX(status)

### 15. article_tag_map（文章-标签关联）
- article_id BIGINT FK knowledge_articles(id)
- tag_id BIGINT FK tags(id)
- PRIMARY KEY (article_id, tag_id)
索引：INDEX(tag_id)

## 关键设计说明
- ID 设计：统一雪花/ULID，便于前端展示与回填；MySQL 使用 BIGINT UNSIGNED
- 全文检索：对 corrected_text、ocr_text、知识库 content 开启 FULLTEXT；如需更强检索，外接 ES/PG-FTS
- 合规与安全：用户数据分区、最小化存储；消息与模型调用日志可设定保留策略
- 软删除：以 status 字段实现归档；必要时增加 deleted_at
- 文件存储：仅存 URL 与散列；原始文件放对象存储（本地/static 或云），避免 DB 存二进制

## 与前端的字段映射建议
- inscriptions 映射：id、title、description、dynasty、year、location、category、cover_image_url、confidence、views
- recognition（识别）结果：inscription_text.ocr_text / corrected_text、ocr_engine、ocr_confidence、corrected_by_user_id
- favorites 页面：favorites(target_type='inscription')
- knowledge 页面：knowledge_articles + article_tag_map
- 对话历史：conversations + messages，并以 related_inscription_id 关联到具体碑文
- 消息内引用：message_citations 使回答可追溯到碑文/文章

## 索引策略
- 高频检索：inscriptions(dynasty, category, views, status)
- 列表与历史：messages(conversation_id, created_at)、conversations(user_id, updated_at)
- 去重与约束：favorites UNIQUE(user_id, target_type, target_id)，tags UNIQUE(name, type)

## 典型使用流程
1) 用户上传图片 → inscriptions + inscription_assets；OCR → inscription_text，生成版本 → inscription_text_versions
2) 用户发起对话（选定碑文）→ conversations；每次问答 → messages；回答内保存引用 → message_citations
3) 用户收藏碑文/会话/消息 → favorites
4) 知识库文章发布与标签 → knowledge_articles + article_tag_map

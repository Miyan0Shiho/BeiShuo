## 功能实现方案

### 问题分析

当用户未上传图片时，点击"详细校对"、"识别结果"、"AI阐释"标签页会直接切换到对应内容区，但此时没有任何数据，导致用户体验不佳。

### 解决方案

1. **修改标签页切换逻辑**：在`switchTab`函数中添加检查，当用户未上传图片时，阻止切换到特定标签页
2. **添加友好提示**：使用现有的通知系统显示提示信息
3. **视觉反馈**：为不可用的标签页按钮添加禁用状态，提供直观的视觉反馈

### 实现步骤

#### 1. 修改 `switchTab` 函数

在 `switchTab` 函数中添加检查逻辑：

* 当用户尝试切换到 `proofread`、`result` 或 `interpretation` 标签页

* 且当前 `recognitionState` 为 `waiting`（未上传图片）

* 则显示提示信息，不执行切换操作

```javascript
const switchTab = (tab) => {
  // 检查是否为需要限制的标签页
  const restrictedTabs = ['proofread', 'result', 'interpretation']
  // 检查是否未上传图片
  const hasNoImage = recognitionState.value === 'waiting'
  
  if (restrictedTabs.includes(tab) && hasNoImage) {
    // 显示友好提示
    appStore.addNotification({
      type: 'info',
      message: '请先上传图片进行识别，再进行后续操作',
      duration: 3000
    })
    // 不执行切换
    return
  }
  
  // 正常切换标签页
  activeTab.value = tab
}
```

#### 2. 为标签页按钮添加禁用状态

为 `proofread`、`result` 和 `interpretation` 标签页按钮添加 `:disabled` 属性和样式：

```html
<button @click="switchTab('proofread')" 
        :disabled="recognitionState === 'waiting'"
        :class="[
          'flex-1 py-4 px-6 font-medium border-b-2 whitespace-nowrap transition-custom',
          activeTab === 'proofread' ? 'text-primary border-primary' : 'text-dark/50 border-transparent hover:text-dark/70',
          recognitionState === 'waiting' ? 'cursor-not-allowed opacity-50 hover:no-underline' : ''
        ]">
    详细校对
</button>
```

（对 `result` 和 `interpretation` 标签页按钮应用相同的修改）

### 预期效果

1. 当用户未上传图片时，"详细校对"、"识别结果"、"AI阐释"标签页按钮显示为禁用状态（半透明，鼠标悬停时显示"禁止"光标）
2. 当用户点击这些禁用的标签页按钮时，会弹出友好提示："请先上传图片进行识别，再进行后续操作"
3. 只有当用户上传图片并完成识别后，这些标签页才能正常访问

### 技术要点

1. 使用现有的 `recognitionState` 状态判断用户是否已上传图片
2. 利用 `appStore.addNotification` 显示友好提示
3. 通过条件样式和 `disabled` 属性提供直观的视觉反馈
4. 保持代码的可维护性和扩展性

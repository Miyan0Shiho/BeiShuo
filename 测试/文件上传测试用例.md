# 文件上传测试用例

## 1. 功能概述

测试文件上传功能的稳定性、格式支持与安全性。

## 2. 支持格式

- 图像：JPG, PNG, BMP, PDF
- 大小限制：≤10MB

## 3. 测试用例

### 3.1 正常上传

| 用例编号   | 文件类型 | 大小 | 预期结果           |
| ---------- | -------- | ---- | ------------------ |
| UPLOAD-001 | PNG 图像 | 5MB  | 上传成功，返回 URL |
| UPLOAD-002 | PDF 文档 | 8MB  | 上传成功，可预览   |

### 3.2 异常上传

| 用例编号       | 文件类型       | 大小 | 预期结果                 |
| -------------- | -------------- | ---- | ------------------------ |
| UPLOAD-ERR-001 | EXE 可执行文件 | 1MB  | 拒绝上传，提示格式不支持 |
| UPLOAD-ERR-002 | 空文件         | 0KB  | 提示文件无效             |

## 4. 安全测试

- 文件重名处理
- 路径遍历攻击防护
- 病毒文件扫描（如有）

## 5. 性能测试

- 并发上传（10 用户同时上传）
- 大文件上传（≈10MB）超时处理

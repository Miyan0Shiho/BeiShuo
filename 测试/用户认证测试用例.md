# 用户认证测试用例

## 1. 功能概述

测试用户登录、注册、密码找回、权限控制等功能。

## 2. 测试范围

- 登录/注销
- 注册流程
- Token 刷新
- 角色权限验证

## 3. 测试用例

### 3.1 登录测试

| 用例编号       | 输入         | 预期结果             |
| -------------- | ------------ | -------------------- |
| AUTH-LOGIN-001 | 正确账号密码 | 登录成功，返回 Token |
| AUTH-LOGIN-002 | 错误密码     | 提示密码错误         |

### 3.2 注册测试

| 用例编号     | 输入     | 预期结果               |
| ------------ | -------- | ---------------------- |
| AUTH-REG-001 | 合规信息 | 注册成功，发送验证邮件 |
| AUTH-REG-002 | 重复邮箱 | 提示邮箱已存在         |

## 4. 安全测试

- 密码强度校验
- Token 过期机制
- 多次失败登录锁定

## 5. 权限测试

| 用户角色 | 可访问模块     | 不可访问模块 |
| -------- | -------------- | ------------ |
| 普通用户 | 上传、查看结果 | 管理后台     |
| 管理员   | 所有功能       | 无           |

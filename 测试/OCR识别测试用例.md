# OCR 识别测试用例

## 1. 功能概述

测试 OCR 系统对图片、PDF 等文件中文字的识别准确率与格式保留能力。

## 2. 测试范围

- 印刷体识别
- 手写体识别
- 多语言支持
- 表格/结构化文本提取

## 3. 测试用例

### 3.1 图像质量测试

| 用例编号 | 图像类型     | 预期识别率 |
| -------- | ------------ | ---------- |
| OCR-001  | 高清扫描文档 | >99%       |
| OCR-002  | 低光照拍摄   | >90%       |

### 3.2 格式测试

| 用例编号    | 输入格式     | 预期输出     |
| ----------- | ------------ | ------------ |
| OCR-TAB-001 | 带表格的 PDF | 表格结构保留 |
| OCR-MIX-001 | 中英文混合   | 正确区分语言 |

## 4. 性能指标

- 单页处理时间 < 3 秒
- 支持批量上传（≤50 文件）

## 5. 测试工具

- Tesseract / 百度 OCR / 自定义模型
- 测试图像库：包含各类样本

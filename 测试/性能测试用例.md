# 性能测试用例

## 1. 测试目标

验证系统在高并发、大数据量下的稳定性与响应能力。

## 2. 测试类型

- 负载测试
- 压力测试
- 稳定性测试（长时间运行）

## 3. 测试场景

### 3.1 接口性能

| 接口     | 预期 QPS | 平均响应时间 |
| -------- | -------- | ------------ |
| 文件上传 | 50 req/s | < 1s         |
| OCR 识别 | 30 req/s | < 3s         |
| AI 解释  | 20 req/s | < 2s         |

### 3.2 用户并发

- 模拟 50 用户同时操作
- 持续运行 30 分钟

## 4. 监控指标

- CPU / 内存使用率
- 数据库连接数
- 错误率（< 1%）

## 5. 测试工具

- JMeter / LoadRunner
- 监控工具：Prometheus + Grafana

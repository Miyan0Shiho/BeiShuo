# OCR参数组合分析报告

## 测试概述
- **测试图片**: 多宝塔碑.jpg（竖排古籍碑文）
- **测试轮次**: 3轮，每轮17个参数组合
- **成功识别率**: 9/17 (52.9%)

## 成功识别的参数组合

### 1. 组合2 - 竖排检测模式（最佳效果）
**参数配置**:
- `det_mode`: "sp" (竖排检测)
- `sp_line_words_angel`: "top2bottom" (从上到下)
- `version`: "v2"

**识别效果**:
- ✅ **成功识别**: "唐西亰千福寺多寳佛"、"塔感應碑文"等完整文本
- 📊 **数据结构**: 字典格式，包含详细的位置信息和置信度
- 🎯 **识别精度**: 高置信度（0.85-1.0），字符位置准确

### 2. 组合9-11 - 竖排检测模式（简化版）
**参数配置**:
- `det_mode`: "sp" (竖排检测)
- `sp_line_words_angel`: "top2bottom" (从上到下)
- `version`: "v2" / "beta" / "default"

**识别效果**:
- ✅ **成功识别**: 8行文本，包含碑文主要内容
- 📊 **数据结构**: 列表格式，每行文本清晰
- 🔄 **版本兼容**: 三个版本均能正确识别

### 3. 组合12-15 - 竖排检测模式（增强版）
**参数配置**:
- `det_mode`: "sp" (竖排检测)
- `sp_line_words_angel`: "top2bottom" (从上到下)
- `version`: "v2"
- 可能包含其他增强参数

**识别效果**:
- ✅ **成功识别**: 8行文本，识别更完整（如"大唐西亰千福寺多寳佛"）
- 📊 **数据结构**: 列表格式
- ✨ **识别改进**: 比组合9-11识别更准确

### 4. 组合16 - 单字符检测模式
**参数配置**:
- `det_mode`: "sp" (竖排检测)
- `char_ocr`: True (单字符检测)
- `version`: "v2"

**识别效果**:
- ✅ **成功识别**: 27个单字符，逐个识别
- 📊 **数据结构**: 列表格式，每个字符单独识别
- 🎯 **适用场景**: 需要极高精度的单字符识别

## 失败识别的参数组合

### 组合1,3-6 - 自动检测模式
**参数配置**:
- `det_mode`: "auto" (自动检测)
- 各种版本组合

**识别效果**:
- ❌ **识别失败**: 返回空列表或无效数据
- 📊 **数据结构**: 空列表
- ⚠️ **问题**: 自动检测无法正确识别竖排古籍

### 组合7-8 - 横排检测模式
**参数配置**:
- `det_mode`: "hp" (横排检测)
- `hp_line_words_angel`: "left2right" (从左到右)

**识别效果**:
- ❌ **识别失败**: 返回空列表
- 📊 **数据结构**: 空列表
- ⚠️ **问题**: 横排模式不适用于竖排古籍

## 关键发现

### 1. 检测模式决定识别效果
- **竖排模式(sp)**: ✅ 成功识别
- **自动模式(auto)**: ❌ 失败
- **横排模式(hp)**: ❌ 失败

### 2. 版本兼容性
- **v2版本**: ✅ 最佳效果
- **beta版本**: ✅ 可用
- **default版本**: ✅ 可用

### 3. 参数组合优化
- **基础竖排**: 组合2（最佳）
- **简化竖排**: 组合9-11（稳定）
- **增强竖排**: 组合12-15（更完整）
- **单字符检测**: 组合16（高精度）

## 推荐参数配置

### 最佳配置（推荐）
```python
{
    "det_mode": "sp",
    "sp_line_words_angel": "top2bottom", 
    "version": "v2"
}
```

### 稳定配置
```python
{
    "det_mode": "sp",
    "sp_line_words_angel": "top2bottom",
    "version": "beta"
}
```

### 高精度配置
```python
{
    "det_mode": "sp", 
    "char_ocr": True,
    "version": "v2"
}
```

## 结论

1. **竖排检测模式(sp)** 是识别竖排古籍的关键参数
2. **从上到下(top2bottom)** 方向设置符合古籍阅读习惯
3. **v2版本** 提供最佳识别效果
4. 避免使用自动检测(auto)和横排检测(hp)模式
5. 对于"多宝塔碑.jpg"这类竖排古籍，推荐使用组合2的参数配置

这些发现为后端OCR集成提供了明确的参数指导，可以确保古籍文本的正确识别。
